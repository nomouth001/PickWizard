======= 오프라인 릴리즈 AAB 명령어 ==================================

cd H:\_Lotto_picker_app\pick_wizard\mobile_app

# flutter clean은 문제있을 때만
flutter clean

flutter pub get
flutter build appbundle --release --target lib/offline/main_offline.dart


- 핵심: `--target lib/offline/main_offline.dart`
- 산출물: `build/app/outputs/bundle/release/app-release.aab`

`main_offline.dart` 파일에도 실행 타깃 주석이 들어있습니다(`flutter run -t lib/offline/main_offline.dart`).

참고로 현재 버전은 그대로 **`1.0.0+1`** 입니다.

pick_wizard/mobile_app/pubspec.yaml 기준:

version: 1.0.0+1
사용자 표시 버전: 1.0.0
Android versionCode: 1
