## 🎯 알고리즘 체계

### Phase 1: 통계 기반 (MVP)

#### **알고리즘 1: 순수 랜덤 (Quick Pick)**

**설명**: 1~45 중 6개를 완전 무작위로 선택하는 baseline 알고리즘

**특징**:
- 가장 공정하고 편향 없는 방법
- 과거 데이터를 사용하지 않음
- 통계적 기대값과 동일한 확률 분포

**파라미터**: 없음 (순수 랜덤)

**비용**: 무료

**구현**:
```python
# 사용 가능한 번호 풀: 1~45 (제외 번호 적용)
available = [1, 2, 3, ..., 45] - exclude_numbers

# 포함 번호가 있으면 먼저 추가
if include_numbers:
    numbers = include_numbers.copy()
else:
    numbers = []

# 나머지 무작위 선택
remaining = 6 - len(numbers)
numbers += random.sample(available, remaining)

# 정렬하여 반환
return sorted(numbers)
```

**예시**:
- 입력: `n_sets=5, exclude_numbers=None, include_numbers=None`
- 출력: 
  ```
  [3, 12, 19, 28, 35, 41]
  [7, 15, 22, 30, 38, 44]
  [1, 9, 18, 25, 33, 40]
  [5, 14, 23, 31, 36, 42]
  [8, 16, 21, 29, 37, 43]
  ```

#### **알고리즘 2: 고급 빈도 분석 (Advanced Frequency)**

**설명**: 과거 출현 빈도를 기반으로 번호를 선택하되, 다양한 필터와 확률 변형을 적용할 수 있는 고도로 커스터마이즈 가능한 알고리즘

**핵심 차별화 요소**:
1. **역확률 샘플링** (Trial02의 핵심)
2. **2회 연속 출현 제외** (직전 2회차 고정)
3. **고빈도 출현 제외** (커스텀 N회차, M회 이상)
4. **직전 회차 확률 할인** 💸 (완전 제외가 아닌 확률 감소)
5. 분석 회차 범위 조정

**조합 예시**:
- `기본 빈도(역) + 직전 회차 패널티` → 빈도 낮은 번호 선호 + 직전 번호 확률 감소
- `최근 트렌드 + 2회 연속 제외 + 고빈도 제외` → 다층 필터링
- `최근 트렌드(역) + 직전 회차 패널티(1/3)` → 강력한 평균 회귀 전략

### 2.1. 파라미터 구조

#### **A. 분석 범위 (Analysis Window)**

**설명**: 빈도 분석에 사용할 과거 회차 범위

**옵션**:
- **전체 회차** (기본값: 모든 데이터)
- **최근 N회차** (입력: 10 ~ 500)
  - 프리셋 버튼:
    - `최근 20회` (약 5개월)
    - `최근 50회` (약 1년)
    - `최근 100회` (약 2년)
    - `최근 200회` (약 4년)
  - 직접 입력: 슬라이더 (10 ~ 500) + 입력창

**UI 예시**:

```
│ 분석 회차 범위                        │
├─────────────────────────────────────┤
│ ○ 전체 회차 (1205회차)               │
│ ● 최근 N회차                         │
│                                     │
│   [20] [50] [100] [200]             │
│                                     │
│   ──────●─────────────────          │
│   10       100      500             │
│                                     │
│   직접 입력: [____] 회차             │
└─────────────────────────────────────┘
```

**코드**:
```python
def get_analysis_window(historical_data, window_type, window_size=None):
    """
    Args:
        window_type: 'all' | 'recent'
        window_size: int (10~500), only for 'recent'
    
    Returns:
        DataFrame: 분석에 사용할 회차 데이터
    """
    if window_type == 'all':
        return historical_data
    else:
        return historical_data.tail(window_size)
```

#### **B. 제외 필터 (Exclusion Filters)**

**설명**: 특정 조건의 번호를 후보에서 제외

##### **B-1. 연속 출현 번호 제외**

**정의**: 직전 2회차에서 연속으로 나온 번호 제외

**특징**: 
- 고정 옵션 (직전 2회차)
- 단순 체크박스 (ON/OFF)
- "2회 연속 나온 번호는 3회차에는 덜 나올 것"이라는 가정

**예시**:
- 1204회: [5, 12, 23, 31, 38, 42]
- 1205회: [5, 15, 23, 28, 36, 44]
- 1206회 생성 시: **5번, 23번 제외** (1204, 1205 연속 출현)

**UI 예시**:
```
┌─────────────────────────────────────┐
│ 🔄 연속 출현 번호 제외                │
├─────────────────────────────────────┤
│ □ 직전 2회차 연속 출현 번호 제외      │
│                                     │
│   (예: 1204회, 1205회 모두 나온 번호) │
└─────────────────────────────────────┘
```

**코드**:
```python
def get_consecutive_2_numbers(historical_data):
    """
    직전 2회차에서 연속 출현한 번호 추출
    
    Returns:
        List[int]: 제외할 번호 리스트
    """
    if len(historical_data) < 2:
        return []
    
    recent_2 = historical_data.tail(2)
    
    # 직전 회차 번호
    prev_numbers = set()
    for i in range(1, 7):
        prev_numbers.add(recent_2.iloc[0][f'num{i}'])
    
    # 최신 회차 번호
    latest_numbers = set()
    for i in range(1, 7):
        latest_numbers.add(recent_2.iloc[1][f'num{i}'])
    
    # 교집합 (연속 출현)
    consecutive = list(prev_numbers & latest_numbers)
    
    return consecutive
```

##### **B-2. 고빈도 출현 번호 제외**

**정의**: 직전 N회차 동안 M회 이상 나온 번호 제외 (연속이 아니어도 됨)

**특징**:
- 커스텀 입력 (N회차, M회 이상)
- "자주 나온 번호는 이제 덜 나올 것"이라는 가정

**옵션**:
- **적용 안 함** (기본값)
- **적용**: 숫자 입력창 2개
  - N회차: 3 ~ 100 (기본값: 10)
  - M회 이상: 2 ~ 20 (기본값: 5)

**예시**:
- 설정: `직전 10회차에서 5회 이상 출현`
- 1196~1205회 중 **12번이 7회 출현** → 12번 제외

**UI 예시**:
```
┌─────────────────────────────────────┐
│ 📊 고빈도 출현 번호 제외              │
├─────────────────────────────────────┤
│ ☑ 직전 [____] 회차에서               │
│        (3~100, 기본: 10)             │
│                                     │
│    [____] 회 이상 출현한 번호 제외    │
│    (2~20, 기본: 5)                   │
│                                     │
│   예: 직전 10회차에서 5회 이상        │
└─────────────────────────────────────┘
```

**코드**:
```python
def get_frequent_numbers(historical_data, lookback, min_frequency):
    """
    직전 N회차에서 M회 이상 출현한 번호 추출
    
    Args:
        lookback: 직전 N회차 (3~100)
        min_frequency: M회 이상 출현 (2~20)
    
    Returns:
        List[int]: 제외할 번호 리스트
    """
    if len(historical_data) < lookback:
        lookback = len(historical_data)
    
    recent_draws = historical_data.tail(lookback)
    frequency = {}
    
    # 빈도 계산
    for idx, row in recent_draws.iterrows():
        for i in range(1, 7):
            num = row[f'num{i}']
            frequency[num] = frequency.get(num, 0) + 1
    
    # min_frequency 이상인 번호 제외
    exclude = [num for num, count in frequency.items() 
               if count >= min_frequency]
    
    return exclude
```

##### **B-3. 직전 회차 출현 번호 확률 할인**

**정의**: 직전 회차에 나온 번호들의 선택 확률을 감소시킴 (완전 제외는 아님)

**특징**:
- 제외가 아닌 **확률 조정** 방식
- "방금 나온 번호는 다시 나올 확률이 낮다"는 가정
- 부드러운 편향 보정 (Soft Penalty)

**옵션**:
- **적용 안 함** (기본값)
- **프리셋 할인율**:
  - `1/2 (50% 할인)`: 확률을 절반으로
  - `1/3 (66% 할인)`: 확률을 1/3로
  - `1/4 (75% 할인)`: 확률을 1/4로
- **커스텀 할인율**: 0.1 ~ 1.0 (0.5 = 50% 할인)

**예시**:
- 1205회: [5, 12, 23, 31, 38, 42]
- 1206회 생성 시:
  - **할인 전**: 5번 확률 = 2.0%
  - **1/2 할인**: 5번 확률 = 1.0%
  - **1/3 할인**: 5번 확률 = 0.67%

**UI 예시**:
```
┌─────────────────────────────────────┐
│ 💸 직전 회차 출현 번호 확률 할인      │
├─────────────────────────────────────┤
│ ☑ 직전 회차 출현 번호 확률 조정       │
│                                     │
│   할인율:                            │
│   ○ 1/2 (50% 할인)                  │
│   ○ 1/3 (66% 할인)                  │
│   ○ 1/4 (75% 할인)                  │
│   ● 커스텀: [0.50] (0.1~1.0)        │
│                                     │
│   예: 0.5 입력 시 확률이 절반으로     │
└─────────────────────────────────────┘
```

**코드**:
```python
def apply_recent_draw_penalty(probabilities, historical_data, penalty_rate):
    """
    직전 회차 출현 번호 확률 할인
    
    Args:
        probabilities: Dict[int, float] (번호 → 확률)
        historical_data: DataFrame
        penalty_rate: float (0.1~1.0, 낮을수록 강한 할인)
            예: 0.5 = 50% 할인, 0.33 = 66% 할인
    
    Returns:
        Dict[int, float]: 조정된 확률
    """
    if len(historical_data) < 1:
        return probabilities
    
    # 직전 회차 번호
    latest_draw = historical_data.tail(1).iloc[0]
    latest_numbers = set()
    for i in range(1, 7):
        latest_numbers.add(latest_draw[f'num{i}'])
    
    # 확률 조정
    adjusted = probabilities.copy()
    for num in latest_numbers:
        if num in adjusted:
            adjusted[num] *= penalty_rate
    
    # 정규화 (합계가 1이 되도록)
    total = sum(adjusted.values())
    adjusted = {num: prob / total for num, prob in adjusted.items()}
    
    return adjusted
```

**동작 예시**:
```python
# 원본 확률
probabilities = {
    5: 0.020,   # 2.0%
    12: 0.022,  # 2.2%
    23: 0.021,  # 2.1%
    ...
}

# 직전 회차: [5, 12, 23, 31, 38, 42]
# 1/2 할인 적용 (penalty_rate=0.5)

    5: 0.010,   # 2.0% → 1.0%
    12: 0.011,  # 2.2% → 1.1%
    23: 0.0105, # 2.1% → 1.05%
    31: (정규화 후 약간 증가),
    ...
}
```

#### **C. 확률 적용 방식 (Probability Mode)**

**설명**: 빈도를 확률로 변환하는 방식 (Trial02의 핵심 차별화!)

**옵션**:

##### **C-1. 정확률 (Normal Probability)**

**정의**: 출현 빈도가 높을수록 선택 확률 높음

**수식**:
```
P(번호) = 출현_빈도(번호) / 전체_출현_횟수
```

**예시**:
- 12번: 150회 출현 → P = 150 / (1205 × 6) = 2.07%
- 43번: 120회 출현 → P = 120 / (1205 × 6) = 1.66%
- **12번이 더 선택될 확률 높음**

**특징**: 직관적, "자주 나온 번호는 다시 나올 것"

---

##### **C-2. 역확률 (Inverse Probability)** ⭐

**정의**: 출현 빈도가 낮을수록 선택 확률 높음 (Trial02의 핵심!)

**수식**:
```
max_freq = max(출현_빈도)
inverse_freq(번호) = max_freq - 출현_빈도(번호) + 1

P(번호) = inverse_freq(번호) / sum(inverse_freq)
```

**예시**:
- 12번: 150회 출현 → inverse = 180 - 150 + 1 = 31
- 43번: 120회 출현 → inverse = 180 - 120 + 1 = 61
- **43번이 더 선택될 확률 높음**

**특징**: 
- "자주 나온 번호는 이제 덜 나올 것" (평균 회귀)
- 통계적 편향 보정
- Trial02의 알고리즘 3, 5, 7, 9의 핵심

**UI 예시**:
```
┌─────────────────────────────────────┐
│ 확률 적용 방식                        │
├─────────────────────────────────────┤
│ ● 정확률 (빈도 ↑ → 확률 ↑)           │
│   "자주 나온 번호는 다시 나올 것"     │
│                                     │
│ ○ 역확률 (빈도 ↑ → 확률 ↓) ⭐       │
│   "자주 나온 번호는 이제 덜 나올 것"  │
│   (통계적 평균 회귀)                 │
└─────────────────────────────────────┘
```

**코드**:
```python
def apply_probability_mode(frequency, mode):
    """
    Args:
        frequency: Dict[int, int] (번호 → 출현 빈도)
        mode: 'normal' | 'inverse'
    
    Returns:
        Dict[int, float]: 번호 → 선택 확률
    """
    if mode == 'normal':
        # 정확률: 빈도 그대로 사용
        total = sum(frequency.values())
        return {num: count / total 
                for num, count in frequency.items()}
    
    else:  # 'inverse'
        # 역확률: 빈도 역전
        max_freq = max(frequency.values())
        inverse = {num: max_freq - count + 1 
                   for num, count in frequency.items()}
        
        total = sum(inverse.values())
        return {num: inv / total 
                for num, inv in inverse.items()}
```

#### **D. 온도 파라미터 (Temperature)** [고급]

**설명**: 확률 분포의 "날카로움" 조정

**수식**:
```
P_adjusted = P^(1/T) / sum(P^(1/T))

T = 0.5: 확률 차이 극대화 (날카로운 분포)
T = 1.0: 원본 확률 유지 (기본값)
T = 2.0: 확률 차이 완화 (평탄한 분포)
```

**UI**: 고급 옵션 (기본값 1.0 고정, Phase 2+에서 활성화)

### 2.2. 알고리즘 2 통합 구현

#### **통합 파라미터 구조**

```python
class FrequencyParams:
    # A. 분석 범위
    window_type: Literal['all', 'recent'] = 'all'
    window_size: Optional[int] = None  # 10~500
    
    # B-1. 연속 출현 제외 (직전 2회차 고정)
    exclude_consecutive_2: bool = False
    
    # B-2. 고빈도 출현 제외 (커스텀)
    exclude_frequent: bool = False
    frequent_lookback: int = 10  # 3~100
    frequent_threshold: int = 5  # 2~20
    
    # B-3. 직전 회차 출현 번호 확률 할인
    apply_recent_penalty: bool = False
    penalty_rate: float = 0.5  # 0.1~1.0 (낮을수록 강한 할인)
    
    # C. 확률 모드
    probability_mode: Literal['normal', 'inverse'] = 'normal'
    
    # D. 온도 (고급)
    temperature: float = 1.0  # 0.1~3.0
```

#### **프리셋 조합**

| 프리셋 이름 | 설명 | 파라미터 |
|------------|------|---------|
| **기본 빈도** | 전체 회차 빈도, 정확률 | `window_type='all', probability_mode='normal'` |
| **기본 빈도 (역)** ⭐ | 전체 회차 빈도, 역확률 | `window_type='all', probability_mode='inverse'` |
| **최근 트렌드** | 최근 50회차, 정확률 | `window_type='recent', window_size=50, probability_mode='normal'` |
| **최근 트렌드 (역)** ⭐ | 최근 50회차, 역확률 | `window_type='recent', window_size=50, probability_mode='inverse'` |

- **고빈도 제외**: `exclude_frequent=True, frequent_lookback=10, frequent_threshold=5`

#### **완전 구현 코드**

```python
class AdvancedFrequencyAlgorithm(LottoAlgorithm):
    """
    고급 빈도 분석 알고리즘
    
    Trial02의 알고리즘 6,7,8,9를 통합
    """
    
    def __init__(self):
        super().__init__(
            algorithm_id=2,
            name="고급 빈도 분석 (Advanced Frequency)",
            description="과거 출현 빈도 기반, 다양한 필터와 역확률 적용 가능",
            cost_per_set=1
        )
    
    def generate_numbers(
        self,
        historical_data: pd.DataFrame,
        n_sets: int = 5,
        exclude_numbers: Optional[List[int]] = None,
        include_numbers: Optional[List[int]] = None,
        
        # A. 분석 범위
        window_type: str = 'all',
        window_size: Optional[int] = None,
        
        # B-1. 연속 출현 제외 (직전 2회차 고정)
        exclude_consecutive_2: bool = False,
        
        # B-2. 고빈도 출현 제외 (커스텀)
        exclude_frequent: bool = False,
        frequent_lookback: int = 10,
        frequent_threshold: int = 5,
        
        # B-3. 직전 회차 출현 번호 확률 할인
        apply_recent_penalty: bool = False,
        penalty_rate: float = 0.5,
        
        # C. 확률 모드
        probability_mode: str = 'normal',
        
        # D. 온도
        temperature: float = 1.0,
        
        **kwargs
    ) -> List[List[int]]:
        """고급 빈도 분석 번호 생성"""
        
        # 파라미터 검증
        valid, error_msg = self.validate_parameters(
            n_sets, exclude_numbers, include_numbers
        )
        if not valid:
            raise ValueError(error_msg)
        
        # 1. 분석 범위 설정
        analysis_data = self._get_analysis_window(
            historical_data, window_type, window_size
        )
        
        # 2. 빈도 계산
        frequency = self._calculate_frequency(analysis_data)
        
        # 3. 제외 필터 적용
        exclude_set = set(exclude_numbers or [])
        
        # B-1. 연속 출현 제외 (직전 2회차 고정)
        if exclude_consecutive_2:
            consecutive_nums = self._get_consecutive_2_numbers(
                historical_data
            )
            exclude_set.update(consecutive_nums)
        
        # B-2. 고빈도 출현 제외 (커스텀)
        if exclude_frequent:
            frequent_nums = self._get_frequent_numbers(
                historical_data,
                frequent_lookback,
                frequent_threshold
            )
            exclude_set.update(frequent_nums)
        
        # 제외 번호 필터링
        frequency = {k: v for k, v in frequency.items() 
                     if k not in exclude_set}
        
        # 포함 번호 제거 (이미 선택됨)
        if include_numbers:
            frequency = {k: v for k, v in frequency.items() 
                         if k not in include_numbers}
        
        # 4. 확률 모드 적용
        probabilities = self._apply_probability_mode(
            frequency, probability_mode
        )
        
        # 5. 직전 회차 확률 할인 (B-3)
        if apply_recent_penalty:
            probabilities = self._apply_recent_draw_penalty(
                probabilities,
                historical_data,
                penalty_rate
            )
        
        # 6. 온도 조정
        probabilities = self._apply_temperature(
            probabilities, temperature
        )
        
        # 7. 번호 생성
        results = []
        numbers_list = list(probabilities.keys())
        probs_list = list(probabilities.values())
        
        for _ in range(n_sets):
            selected = []
            
            # 포함 번호 먼저 추가
            if include_numbers:
                selected.extend(include_numbers)
            
            # 확률 기반 샘플링
            remaining = 6 - len(selected)
            if remaining > 0:
                chosen = np.random.choice(
                    numbers_list,
                    size=remaining,
                    replace=False,
                    p=probs_list
                )
                selected.extend(chosen.tolist())
            
            results.append(sorted(selected))
        
        return results
    
    def _get_analysis_window(self, data, window_type, window_size):
        """분석 범위 추출"""
        if window_type == 'all':
            return data
        else:
            return data.tail(window_size or 50)
    
    def _calculate_frequency(self, data):
        """빈도 계산"""
        frequency = {}
        for idx, row in data.iterrows():
            for i in range(1, 7):
                num = row[f'num{i}']
                frequency[num] = frequency.get(num, 0) + 1
        return frequency
    
    def _get_consecutive_numbers(self, data, lookback, threshold):
        """연속 출현 번호 추출"""
        recent = data.tail(lookback)
        exclude = []
        
        for num in range(1, 46):
            consecutive = 0
            max_consecutive = 0
            
            for idx, row in recent.iterrows():
                numbers = [row[f'num{i}'] for i in range(1, 7)]
                if num in numbers:
                    consecutive += 1
                    max_consecutive = max(max_consecutive, consecutive)
                else:
                    consecutive = 0
            
            if max_consecutive >= threshold:
                exclude.append(num)
        
        return exclude
    
    def _get_frequent_numbers(self, data, lookback, threshold):
        """중복 출현 번호 추출"""
        recent = data.tail(lookback)
        frequency = {}
        
        for idx, row in recent.iterrows():
            for i in range(1, 7):
                num = row[f'num{i}']
                frequency[num] = frequency.get(num, 0) + 1
        
        exclude = [num for num, count in frequency.items() 
                   if count >= threshold]
        return exclude
    
    def _apply_probability_mode(self, frequency, mode):
        """확률 모드 적용"""
        if mode == 'normal':
            # 정확률
            total = sum(frequency.values())
            return {num: count / total 
                    for num, count in frequency.items()}
        else:
            # 역확률 ⭐
            max_freq = max(frequency.values())
            inverse = {num: max_freq - count + 1 
                       for num, count in frequency.items()}
            total = sum(inverse.values())
            return {num: inv / total 
                    for num, inv in inverse.items()}
    
    def _apply_temperature(self, probabilities, temperature):
        """온도 조정"""
        if temperature == 1.0:
            return probabilities
        
        # P^(1/T)
        adjusted = {num: p ** (1/temperature) 
                    for num, p in probabilities.items()}
        
        # 정규화
        total = sum(adjusted.values())
        return {num: adj / total 
                for num, adj in adjusted.items()}
    
    def _get_consecutive_2_numbers(self, historical_data):
        """직전 2회차 연속 출현 번호 추출"""
        if len(historical_data) < 2:
            return []
        
        recent_2 = historical_data.tail(2)
        
        # 직전 회차 번호
        prev_numbers = set()
        for i in range(1, 7):
            prev_numbers.add(recent_2.iloc[0][f'num{i}'])
        
        # 최신 회차 번호
        latest_numbers = set()
        for i in range(1, 7):
            latest_numbers.add(recent_2.iloc[1][f'num{i}'])
        
        # 교집합 (연속 출현)
        consecutive = list(prev_numbers & latest_numbers)
        
        return consecutive
    
    def _apply_recent_draw_penalty(self, probabilities, historical_data, penalty_rate):
        """직전 회차 출현 번호 확률 할인"""
        if len(historical_data) < 1:
            return probabilities
        
        # 직전 회차 번호
        latest_draw = historical_data.tail(1).iloc[0]
        latest_numbers = set()
        for i in range(1, 7):
            latest_numbers.add(latest_draw[f'num{i}'])
        
        # 확률 조정
        adjusted = probabilities.copy()
        for num in latest_numbers:
            if num in adjusted:
                adjusted[num] *= penalty_rate
        
        # 정규화 (합계가 1이 되도록)
        total = sum(adjusted.values())
        adjusted = {num: prob / total for num, prob in adjusted.items()}
        
        return adjusted
    
    def get_default_parameters(self):
        """기본 파라미터"""
        return {
            'window_type': 'all',
            'window_size': None,
            'exclude_consecutive_2': False,
            'exclude_frequent': False,
            'frequent_lookback': 10,
            'frequent_threshold': 5,
            'apply_recent_penalty': False,
            'penalty_rate': 0.5,
            'probability_mode': 'normal',
            'temperature': 1.0
        }
```
