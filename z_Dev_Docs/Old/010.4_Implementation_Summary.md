## 🧠 알고리즘 3: LSTM 고급 분석

### 통합 범위
- Trial01/02의 알고리즘 2, 3, 4, 5 → **하나로 통합**

### 주요 기능

#### A. 학습 방식 ⭐

**Non-Cumulative (비누적 학습)**
- 매번 전체 데이터로 처음부터 새로 학습
- ✅ 깨끗한 상태, 재현성 보장
- ❌ 학습 시간 오래 걸림
- 비용: 3코인 (normal), 4코인 (inverse)

**Cumulative (누적 학습)**
- 이전 모델 저장 → 신규 데이터만 추가 학습
- ✅ 학습 속도 빠름, 장기 패턴 누적
- ❌ Overfitting 위험
- 비용: 2코인 (normal), 5코인 (inverse)

#### B. 확률 방식 ⭐

**정확률 (Normal)**
- LSTM 출력 확률 그대로 사용
- "AI가 예측한 번호를 따른다"

**역확률 (Inverse)** ⭐
- LSTM 확률을 역전시켜 샘플링
- "AI가 예측한 번호는 이미 충분히 나왔을 것"
- 빈도 기반 역확률과 동일한 철학

#### C. 학습 범위
- Window Size: 10~500 (기본값: 100)

#### D. 모델 구조
- Hidden Size: 32, 64, 128 ⭐, 256
- Num Layers: 1, 2 ⭐, 3
- Dropout: 0.0~0.5 (기본값: 0.2)

#### E. 학습 설정
- Num Epochs: 20, 50 ⭐, 100, 200
- Learning Rate: 0.0001, 0.001 ⭐, 0.01
- Batch Size: 16, 32 ⭐, 64

#### F. 추가 옵션
- 직전 회차 확률 할인 (빈도 기반과 동일)
- 온도 조정

## 🎨 알고리즘 4: 패턴 분석

### 통합 범위
- Trial04 (범위 패턴) + Trial05 (순위 패턴) → **하나로 통합**

### 주요 기능

#### A. 패턴 타입 ⭐

**범위 패턴 (Range Pattern)**
- 1~45를 N개 구간으로 분할
- 구간 옵션: 2, 3, 5 ⭐, 10
- 예: [5,12,23,31,38,42] → "ABCDEE"

**순위 패턴 (Rank Pattern)**
- 출현 빈도 순위의 조합
- 조합 크기: 3 ⭐, 4, 5, 6
- 순위 계산: 누적 빈도 ⭐, 최근 N회차

#### B. 분석 범위
- 전체 회차 (기본값)
- 최근 N회차 (10~500)

#### C. 상위 패턴 개수
- 5, 10 ⭐, 20, 30개

#### D. 패턴 내 확률 분포
- **균등**: 구간/순위 내 모든 번호 동일 확률
- **빈도 기반**: 출현 빈도 높은 번호 우선
- **역확률** ⭐: 출현 빈도 낮은 번호 우선

#### E. 패턴 선택 확률
- **정확률**: 빈도 높은 패턴 우선
- **역확률** ⭐: 빈도 낮은 패턴 우선
