# 알고리즘 2, 3 완전히 동일
def _apply_temperature(
    self,
    probabilities: Dict[int, float],
    temperature: float
) -> Dict[int, float]:
    """온도 조정"""
    if temperature == 1.0:
        return probabilities
    
    adjusted = {num: p ** (1/temperature) 
                for num, p in probabilities.items()}
    
    total = sum(adjusted.values())
    if total > 0:
        return {num: adj / total for num, adj in adjusted.items()}
    return probabilities
```

**영향 범위**:
- **중복 라인 수**: 36 라인 (18라인 × 2개 파일)

            probabilities: 원본 확률 분포
            temperature: 온도 (0.1~3.0)
                - < 1.0: 확률 차이 극대화 (날카로운 분포)
                - = 1.0: 원본 유지
                - > 1.0: 확률 차이 완화 (평탄한 분포)
        
        Returns:
            조정된 확률 분포
        """
        if temperature == 1.0:
            return probabilities
        
        adjusted = {num: p ** (1/temperature) 
                    for num, p in probabilities.items()}
        
        total = sum(adjusted.values())
        if total > 0:
            return {num: adj / total for num, adj in adjusted.items()}
        return probabilities
```

**절감 효과**:
- ❌ 중복 제거 전: 36 라인
- ✅ 중복 제거 후: 18 라인 (base) + 2 라인 (호출) = 20 라인
- 💰 **절감**: 16 라인 (44% 감소)
