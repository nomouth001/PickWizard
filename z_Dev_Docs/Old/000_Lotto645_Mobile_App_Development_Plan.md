## 💡 3. 핵심 기능 설계

### 3.1 MVP (Minimum Viable Product) - Phase 1

#### 3.1.1 필수 기능

**1️⃣ 번호 생성 엔진**
- **9가지 알고리즘 선택**
  - 알고리즘 1~9 (Trial02 기반)
  - 각 알고리즘 설명 카드
  - "추천 알고리즘" 자동 제안 (최근 성능 기반)
- **생성 옵션**
  - 세트 수: 1~10개
  - 제외 번호 설정
  - 포함 번호 설정 (선택)
- **결과 화면**
  - 번호 세트 리스트
  - QR 코드 생성 (로또 판매점 제출용)
  - 저장 및 공유 기능

**2️⃣ 당첨 확인**
- 저장된 번호와 최신 당첨번호 자동 비교
- 등수/상금 표시
- 히스토리 누적

**3️⃣ 통계 대시보드**
- 번호별 출현 빈도 (막대 그래프)
- 최근 10회 트렌드
- ABCDE 패턴 분포
- 홀짝/고저 비율

**4️⃣ 최신 회차 정보**
- 실시간 크롤링 (Trial01 `lotto_crawler.py` 활용)
- 당첨번호/보너스
- 당첨금/당첨자 수
- 판매 현황

### 4.3 데이터베이스 스키마 (핵심 테이블)

```sql
-- 사용자
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    email VARCHAR(255) UNIQUE,
    password_hash VARCHAR(255),
    nickname VARCHAR(50),
    subscription_tier VARCHAR(20) DEFAULT 'free', -- free/premium
    created_at TIMESTAMP DEFAULT NOW(),
    last_login TIMESTAMP
);

-- 로또 회차 데이터
CREATE TABLE lotto_draws (
    draw_no INTEGER PRIMARY KEY,
    num1 SMALLINT NOT NULL,
    num2 SMALLINT NOT NULL,
    num3 SMALLINT NOT NULL,
    num4 SMALLINT NOT NULL,
    num5 SMALLINT NOT NULL,
    num6 SMALLINT NOT NULL,
    bonus SMALLINT NOT NULL,
    draw_date DATE NOT NULL,
    prize_1st BIGINT,
    prize_2nd BIGINT,
    prize_3rd BIGINT,
    winners_1st INTEGER,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 생성된 번호 히스토리
CREATE TABLE generated_numbers (
    id SERIAL PRIMARY KEY,
    user_id INTEGER REFERENCES users(id),
    algorithm_id INTEGER NOT NULL, -- 1~9
    draw_no INTEGER REFERENCES lotto_draws(draw_no),
    numbers SMALLINT[] NOT NULL, -- {5, 12, 23, 31, 38, 42}
    parameters JSONB, -- 알고리즘 파라미터
    created_at TIMESTAMP DEFAULT NOW()
);

-- 당첨 결과
CREATE TABLE winning_results (
    id SERIAL PRIMARY KEY,
    generated_id INTEGER REFERENCES generated_numbers(id),
    draw_no INTEGER REFERENCES lotto_draws(draw_no),
    matched_count SMALLINT,
    rank SMALLINT, -- 1~5 or 0 (꽝)
    has_bonus BOOLEAN,
    prize_amount BIGINT,
    checked_at TIMESTAMP DEFAULT NOW()
);

-- 알고리즘 성능 통계 (집계 테이블)
CREATE TABLE algorithm_performance (
    id SERIAL PRIMARY KEY,
    algorithm_id INTEGER NOT NULL,
    period_start INTEGER, -- 시작 회차
    period_end INTEGER,   -- 종료 회차
    total_sets INTEGER,
    rank_1 INTEGER DEFAULT 0,
    rank_2 INTEGER DEFAULT 0,
    rank_3 INTEGER DEFAULT 0,
    rank_4 INTEGER DEFAULT 0,
    rank_5 INTEGER DEFAULT 0,
    avg_matched NUMERIC(3,2),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- AI 모델 버전 관리
CREATE TABLE ai_models (
    id SERIAL PRIMARY KEY,
    version VARCHAR(20) NOT NULL,
    model_path VARCHAR(255),
    trained_on_draws INTEGER, -- 학습에 사용된 회차 수
    validation_accuracy NUMERIC(5,4),
    status VARCHAR(20) DEFAULT 'active', -- active/deprecated
    created_at TIMESTAMP DEFAULT NOW()
);
```
