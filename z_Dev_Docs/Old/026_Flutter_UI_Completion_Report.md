### 7. 문제 해결 가이드

#### 7.1 백엔드 서버가 시작되지 않음

**증상**:
```
ERROR: [Errno 10048] error while attempting to bind on address ('0.0.0.0', 8000)
```

**원인**: 포트 8000이 이미 사용 중

**해결**:
```powershell
# 포트 8000 사용 프로세스 확인
netstat -ano | findstr :8000

# 출력 예:
# TCP    0.0.0.0:8000    0.0.0.0:0    LISTENING    12345

# 프로세스 종료 (PID: 12345)
taskkill /PID 12345 /F

# 서버 재시작
cd luckyai_645/backend
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

---

**증상**:

Error: Compilation failed.
lib/presentation/providers/xxx.dart:XX:XX:

**원인**: 코드 생성 미완료 또는 import 누락

cd luckyai_645/mobile_app

flutter run -d chrome --debug

#### 7.3 API 호출 실패 (CORS 에러)

**증상 (Console)**:
```
Access to XMLHttpRequest at 'http://localhost:8000/api/lotto/latest' 
from origin 'http://localhost:xxxxx' has been blocked by CORS policy
```

**원인**: CORS 설정 누락

**해결**:
1. `backend/app/main.py` 확인:
```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],  # 또는 ["http://localhost:*"]
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

2. 서버 재시작

#### 7.4 코인이 차감되지 않음

**증상**: 번호 생성 후 코인 잔액 변화 없음

**원인**: 백엔드 코인 차감 로직 누락 또는 Provider 갱신 실패

**디버깅**:
1. **백엔드 로그 확인**:
```
INFO: POST /api/generate
INFO: User: abc123, Algorithm: 1, Sets: 1, Cost: 5
INFO: Coin deducted: 50 → 45
```

2. **Network 탭 확인**:
   - POST /api/generate 응답에 `cost: 5` 포함 확인

3. **Provider 갱신 확인**:
   - `generate_provider.dart`에서 `ref.invalidate(coinBalanceProvider)` 호출 확인
