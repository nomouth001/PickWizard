## 1. 제품 개요

### 1.1 제품 소개

**LuckyAI 645**는 AI 기반 다중 알고리즘을 활용한 로또 6/45 번호 생성 및 분석 플랫폼입니다. 9가지 검증된 알고리즘과 LSTM 딥러닝을 통해 과학적이고 투명한 번호 생성 서비스를 제공합니다.

### 1.2 제품 포지셔닝

```
기존 로또 앱의 문제점:
❌ 알고리즘 블랙박스 (신뢰성 부족)
❌ 단순 랜덤 또는 규칙 기반
❌ 성능 검증 데이터 없음
❌ 복잡한 UI/UX

LuckyAI 645의 차별점:
✅ 9가지 알고리즘 투명 공개
✅ LSTM 딥러닝 + Ensemble
✅ 1,169회차 전체 백테스팅 결과 공개
✅ 직관적이고 모던한 UI
✅ 교육 콘텐츠 제공
```

### 1.3 핵심 가치 제안 (UVP)

> **"당신만의 AI 로또 분석가"**
> 
> 투명하고 검증된 AI 알고리즘으로  
> 과학적 근거를 제공하는 로또 번호 생성 플랫폼

### 1.4 타겟 시장

- **주요 시장**: 대한민국 로또 6/45 참여자
- **시장 규모**: 연간 5조 원 (2024년 기준)
- **주간 참여자**: 약 800만 명
- **모바일 사용자**: 전체의 65%
- **타겟 사용자 수**: Year 1 - 10K, Year 2 - 50K, Year 3 - 150K

### 4.2 번호 생성 및 구매

**시나리오**: 김데이터가 토요일 저녁 번호를 생성하는 경우

**단계별 플로우**:
1. **앱 실행** (메인 화면)
   - 상단: 최신 회차 정보 (1170회)
   - 중앙: "번호 생성하기" 버튼
   - 하단: 내비게이션 바

2. **알고리즘 선택 화면**
   - 9개 알고리즘 카드 리스트
   - 각 카드에 표시:
     - 알고리즘 이름
     - 짧은 설명 (1줄)
     - 최근 100회차 성능 (평균 매칭 2.35개)
     - "추천" 배지 (성능 기반)
   - [상세 정보] 버튼

3. **알고리즘 2 선택** (LSTM)
   - 상세 화면 모달
     - 알고리즘 설명 (쉬운 언어)
     - 과거 성능 그래프
     - 장단점
   - [이 알고리즘으로 생성] 버튼

4. **옵션 설정** (선택)
   - 세트 수: 1~10개 (기본 5개)
   - 제외 번호: 빈 칸 (선택)
   - 포함 번호: 빈 칸 (선택)
   - [생성하기] 버튼

5. **번호 생성 중** (로딩)
   - 애니메이션 (2초)
   - "AI가 번호를 분석 중입니다..."

6. **결과 화면**
   - 5세트 번호 표시
     - 세트 1: [5, 12, 23, 31, 38, 42]
     - 세트 2: [7, 14, 22, 30, 35, 41]
     - ...
   - 각 세트별:
     - [QR 코드] 버튼
     - [저장] 버튼
     - [공유] 버튼

7. **QR 코드 생성**
   - 세트 1 선택 → QR 코드 전체화면
   - 화면 밝기 자동 최대
   - "판매점에서 스캔하세요"
   - [다운로드] 버튼

8. **저장 확인**
   - "1170회차 번호 5세트 저장됨"
   - 토스트 메시지
   - 히스토리에 자동 추가

**예상 소요 시간**: 1분

**성공 지표**:
- 번호 생성 → QR 생성 < 30초
- QR 코드 스캔 성공률 > 95%
- 저장 완료율 > 80%

     - "평균 2.2개 일치"
     - "Algorithm 2가 가장 높은 성능"

**예상 소요 시간**: 자동 (사용자 액션 불필요)

**성공 지표**:
- 당첨번호 크롤링 성공률 > 99%
- 매칭 계산 정확도 100%
- 푸시 알림 도달률 > 90%

### 4.4 알고리즘 성능 비교

**시나리오**: 김데이터가 어떤 알고리즘이 좋은지 비교하고 싶은 경우

**단계별 플로우**:
1. **메인 화면** → [통계] 탭
   
2. **통계 대시보드**
   - 상단: 필터
     - 기간: 최근 100회 / 1년 / 전체
     - 알고리즘: 전체 / 개별 선택
   - "최근 100회차 기준"으로 기본 설정

3. **알고리즘 순위 카드**
   ```
   🥇 Algorithm 2 (LSTM)
      평균 매칭: 2.35개
      5등 이상: 68회 (1.16%)
      적중률: 49.1%
   
   🥈 Algorithm 6 (Frequency)
      평균 매칭: 2.31개
      5등 이상: 65회 (1.11%)
      적중률: 48.5%
   ```

---

### 15.2 비즈니스 제약

1. **예산**: Year 1 ₩86M (인프라 ₩1M/월, 인건비 ₩60M)
2. **팀 규모**: 3명 (백엔드 1, 프론트 1, PM/디자인 1)
3. **개발 기간**: MVP 3개월, 공식 출시 6개월
4. **마케팅 예산**: Year 1 ₩20M

---

### 15.3 법적 제약

1. **사행행위법**: 직접 구매 기능 불가 (QR 생성만)
2. **개인정보보호법**: PIPA 준수, 최소 수집
3. **저작권**: 동행복권 로고/브랜드 미사용
4. **면책 조항**: "결과 보장 불가" 명시

1. **크롤링 제한**: 로봇 차단 가능성 (Selenium 백업)
2. **API 부재**: 동행복권 공식 API 없음
3. **과거 데이터**: CSV 파일 의존 (검증 필요)
