# 오프라인 전용 앱 (045)

PickWizard 오프라인 빌드 — 서버 없이 동작하는 복권 번호 추천 보조 앱입니다.

## 실행 방법

- **Chrome (디버그)**  
  ```bash
  flutter run -d chrome --debug -t lib/offline/main_offline.dart
  ```  
  Chrome에서는 AdMob 미지원이라 배너가 비어 보일 수 있습니다.

- **실기기 (Android/iOS)**  
  기기 연결 후:  
  ```bash
  flutter run -t lib/offline/main_offline.dart
  ```  
  배너 광고·내 번호 저장·언어 유지 등 실제 동작 확인용으로 사용하세요.

## 화면 구성

1. **스플래시** (`OfflineSplashScreen`): 앱 로고/타이틀 표시 후 약 2초 뒤 홈으로 자동 전환.
2. **홈/번호 생성** (`OfflineHomeScreen`): **헤더·푸터 배너 광고**, 당첨 확인 안내 문구, 언어 선택, 알고리즘 선택(자동선택, 만 번 뽑기 6개), 번호 생성 버튼. AppBar에 **내 번호** 진입 버튼.
3. **결과** (`OfflineResultScreen`): 상단 배너 광고(`BannerAdWidget`), 생성된 번호 세트(세트1, 세트2…), **내 번호로 저장** 탭(탭 시에만 Hive에 저장), 하단 배너.
4. **내 번호** (`OfflineMyNumbersScreen`): 저장된 번호 목록. 항목 탭 시 상세(전체 세트) 보기, 삭제(확인 다이얼로그 후 삭제). 비어 있으면 빈 화면 문구(다국어)와 “번호 생성” 유도 문구 표시.

## 주요 동작

- **언어 선택 유지**: 설정에서 선택한 언어는 `SharedPreferences`에 저장되며, 다음 실행 시 해당 언어로 시작합니다. 기기 언어가 우리 지원 언어(ko/en/zh/vi/th/ja)에 있으면 첫 실행 시 그 언어로, 없으면 영어로 켜집니다.
- **내 번호 저장**: 번호 생성 후 결과 화면에서만 “내 번호로 저장”을 눌렀을 때 Hive에 저장됩니다. 홈에서 생성만 해서는 저장되지 않습니다.
- **광고**: `BannerAdWidget()` 사용. **홈** 화면 헤더·푸터, **결과** 화면 상단·하단에 배치. 실기기에서 배너 노출 확인 가능.

## 의존성

- `shared_preferences`: 언어 저장/로드
- Hive: 내 번호 로컬 저장
- AdMob(실기기): 홈·결과 화면 배너
