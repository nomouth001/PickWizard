## 🧪 테스트 시나리오

### 테스트 1: 앱 시작 및 초기화 ✅

**기대 동작**:
1. 스플래시 화면 표시 (3초)
2. Hive 초기화 메시지 출력: `✅ Hive 초기화 완료`
3. 홈 화면으로 자동 전환

**확인 사항**:
- [ ] 스플래시 화면 로고/앱 이름 표시
- [ ] 로딩 인디케이터 동작
- [ ] 콘솔에 `✅ Hive 초기화 완료` 출력
- [ ] 3초 이내 홈 화면 전환

---

### 테스트 2: 홈 화면 - 최신 회차 조회 ✅

**기대 동작**:
1. 홈 화면 로드 시 최신 회차 정보 표시
2. API 호출: `GET http://localhost:8000/api/draws/latest`
3. 당첨번호 6개 + 보너스 1개 표시

**확인 사항**:
- [ ] 회차 번호 표시 (예: "1205회")
- [ ] 추첨일 표시 (예: "2024년 10월 19일")
- [ ] 로또 공 7개 정상 표시 (색상 구분)
- [ ] 보너스 공 보라색으로 표시
- [ ] Pull-to-refresh 동작 (아래로 드래그)

---

### 테스트 3: 번호 생성 화면 - 알고리즘 선택 ✅

**기대 동작**:
1. "번호 생성하기" 버튼 클릭
2. 알고리즘 목록 조회: `GET http://localhost:8000/api/algorithms`
3. 알고리즘 목록 표시 (라디오 버튼)

**확인 사항**:
- [ ] 알고리즘 7개 이상 표시
- [ ] 각 알고리즘 이름, 설명, 비용 표시
- [ ] 무료 알고리즘 "무료" 표시 (초록색)
- [ ] 유료 알고리즘 "N코인" 표시 (파란색)
- [ ] 라디오 버튼 선택 가능

---

### 테스트 4: 번호 생성 화면 - 생성 개수 조정 ✅

**기대 동작**:
1. 슬라이더로 생성 개수 조정 (1~10개)
2. 실시간 개수 표시 업데이트

**확인 사항**:
- [ ] 슬라이더 최소값 1
- [ ] 슬라이더 최대값 10
- [ ] 슬라이더 이동 시 숫자 실시간 변경
- [ ] 9개 구간 (1~10)

---

### 테스트 5: 번호 생성 실행 ✅

**테스트 케이스 A: 무료 알고리즘 (ID=1)**

**기대 동작**:
1. 알고리즘 선택 (예: "순수 랜덤")
2. 생성 개수 선택 (예: 5개)
3. "번호 생성" 버튼 클릭
4. API 호출: `POST http://localhost:8000/api/generation`
   ```json
   {
     "algorithm_id": 1,
     "n_sets": 5
   }
   ```
5. 결과 화면으로 자동 전환

**확인 사항**:
- [ ] 로딩 인디케이터 표시
- [ ] API 응답 성공 (HTTP 200)
- [ ] 결과 화면 전환
- [ ] 5개 번호 세트 표시
- [ ] 각 세트 번호 6개 (1~45 사이)
- [ ] 번호 오름차순 정렬
- [ ] 알고리즘 이름 표시

---

**테스트 케이스 B: 유료 알고리즘 (코인 부족 시나리오)**

**기대 동작**:
1. 유료 알고리즘 선택 (예: "고급 빈도 분석", 5코인)
2. "번호 생성" 버튼 클릭
3. API 호출 실패: HTTP 402 (코인 부족)
4. 에러 스낵바 표시: "코인이 부족합니다"

**확인 사항**:
- [ ] 에러 메시지 표시 (빨간색)
- [ ] 결과 화면으로 이동하지 않음
- [ ] 생성 화면 유지

---

### 테스트 6: 결과 화면 ✅

**기대 동작**:
1. 알고리즘 정보 카드 표시
2. 각 번호 세트 카드 표시 (세트 번호 + 로또 공 6개)
3. "내 번호로 저장" 버튼

**확인 사항**:
- [ ] 알고리즘 이름 표시
- [ ] 생성 개수 표시 (예: "5개 생성 완료")
- [ ] 각 세트 "세트 N" 표시
- [ ] 로또 공 색상 올바름 (1~10=노랑, 11~20=파랑, ...)
- [ ] "내 번호로 저장" 버튼 존재
- [ ] 공유 아이콘 버튼 (우측 상단)

---

### 테스트 7: Hive 로컬 저장 확인 ✅

**기대 동작**:
1. 번호 생성 후 자동으로 Hive에 저장

**확인 방법**:
1. 번호 생성 (테스트 5 수행)
2. 앱 종료 (`Ctrl+C` 또는 창 닫기)
3. 앱 재시작 (`flutter run`)
4. (추후 "내 번호" 화면 구현 시 확인)

**확인 사항**:
- [ ] 번호 생성 시 로컬 저장 성공
- [ ] 앱 재시작 후 데이터 유지
- [ ] Hive Box 정상 동작

3. HTTP 400 에러
4. 에러 스낵바: "잘못된 요청입니다"

**확인 사항**:
- [ ] 에러 메시지 표시
